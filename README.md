## CN2 GIA、AS9929、4837：线路差在哪，为什么它比 CPU 更影响体验

跨境线路的质量排序大致是 **CN2 GIA > AS9929 > 4837 > 普通 BGP**。CN2 GIA 是中国电信的精品骨干网，电信、联通、移动三网回程都走它，延迟低、丢包少。最容易感知的差距在晚上 8 点到 11 点：普通 BGP 线路这个时段延迟可能从 150ms 直接飙到 300ms 以上，CN2 GIA 基本还在正常区间。AS9929 是联通骨干网，比普通 BGP 好一截，价格比 CN2 GIA 便宜。4837 和普通 BGP 属于共享带宽的大众线路，高峰期容易堵。

## 数据中心 IP、原生 IP、住宅 IP：你需要哪一种

VPS 拿到的 IP 分三种，价格和用途差别很大。

**数据中心 IP**：商业机房的 IP 段。Netflix、Disney+、BBC iPlayer 这类流媒体和 TikTok 会直接识别并限制。

**原生 IP**：目标地区 ISP 实际分配给本地用户的地址，被平台标记的概率低得多。用英国原生 IP 访问 BBC iPlayer 通常直接通，同地区的数据中心 IP 大概率提示地区限制。

**住宅 IP / 双 ISP IP**：归属真实住宅网络，主要用于 TikTok 账号运营、跨境电商这类对 IP 纯净度要求高的场景。代价是这类 IP 的线路通常没做过专门优化，直连国内的延迟和稳定性一般。

判断规则很简单：建站、搭服务、跑脚本，普通 IP 就够，没必要为用不上的特性多付钱；做流媒体解锁才需要原生 IP；TikTok 或跨境电商才轮到住宅 IP。

AkkoCloud 公开的套餐信息只涉及线路，**没有标注原生 IP 或住宅 IP**。如果这两项是你的硬需求，下单前先跟商家确认，别默认它自带。
